# Регистрация и вход

## Регистрация

**Поля** — все обязательные:

- **Имя** и **фамилия** — от **1 до 30** символов: русские или латинские буквы (можно вперемешку); **пробел** или **дефис** — только между буквами.
- **Телефон** — `+7` и **10 цифр**. В API можно и без `+7`: `9001234567`, `89001234567`, `79001234567`, с пробелами, дефисами и скобками; буквы и `+8…` — ошибка 422. В интерфейсе `+7` подставлен и не редактируется, цифры вводятся по маске `000 000-00-00`; если ввести или вставить 11 цифр с **7** или **8** в начале, первая отбрасывается.
- **Пароль** — от **8 до 30** символов, **без пробелов**; обязательно есть **строчная** и **заглавная** латинская буква, **цифра** и **спецсимвол** (например `!@#$%^&*`); кроме них можно любые символы, в том числе русские буквы. Под полем — список этих правил: выполненное — зелёная галочка, невыполненное — красный крестик.
- **Повтор пароля** — совпадает с паролем (только в интерфейсе).

**После регистрации:**

- у клиента открыт счёт **«Основной»** с балансом **0 ₽**, карты нет;
- интерфейс переходит на **экран входа** с подставленным телефоном.

**Ошибки:**

- телефон уже зарегистрирован, в том числе номер клиента **другого банка** из справочника — **409** «Этот номер уже зарегистрирован»;
- пароль не по правилам — **422** «Пароль: 8–30 символов без пробелов, строчная и заглавная латинская буква, цифра и спецсимвол».

## Вход

**Два шага:** телефон и пароль → **код из SMS** → вход выполнен (в API — `access_token`).

**Код из SMS:**

- **4 цифры**, действует **5 минут** (ровно через 5 минут уже истёк), **3 попытки**;
- новый код — не раньше чем через **60 секунд**; новый код **заменяет** старый, попытки при этом **не обнуляются**;
- **новый вход** (снова телефон и пароль) отменяет прежний незавершённый вход — работает только код из **последней** SMS;
- использованный код **повторно не принимается**.

**Что видит клиент на шаге кода:** номер в виде `+7 999 ***-45-67`, **4 ячейки** для цифр, **таймер** до повторной отправки (идёт по часам банка). Код отправляется **сам** после ввода 4-й цифры. Если обновить страницу, шаг кода **сохраняется**; если код за это время истёк, на шаге написано «Срок действия кода истёк» и можно запросить новый.

**Ошибки:**

- неверный пароль или незарегистрированный телефон — **одна и та же** ошибка **400** «Неверный телефон или пароль» (пароль из одних пробелов — тоже); пустой пароль — **422** «Обязательное поле»;
- клиент заблокирован — **403** «Пользователь заблокирован», в том числе если его заблокировали **между** паролем и кодом (и при вводе кода, и при запросе нового);
- неверный код — **400** «Неверный код. Осталось попыток: N»;
- третий неверный код — **400** «Превышено число попыток ввода кода», код **сгорает**, вход начинается заново: новый код для этого входа уже не запросить — **404** «Запрос на вход не найден, начните заново»;
- код истёк — **400** «Срок действия кода истёк, запросите новый»;
- новый код запрошен раньше 60 секунд — **429** «Новый код можно запросить чуть позже».

## Сессия

- Токен действует **60 минут**: ровно через 60 минут после входа он уже не работает.
- Запрос **без токена** — **401** «Нужно войти заново», с **истёкшим** токеном — **401** «Сессия истекла, войдите снова»; интерфейс переводит на **экран входа** с плашкой «Сессия истекла».
- Если клиента **заблокировали**, любой его запрос — **403**.
- **«Выйти»** удаляет токен из браузера и открывает экран входа. На сервере токен не отзывается — он действует до истечения срока.
