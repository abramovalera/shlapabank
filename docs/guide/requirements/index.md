## Общие правила

- Все суммы — в **рублях**, с **копейками** (не больше **2 знаков** после запятой). **Ноль**, **отрицательная** сумма, **3 знака** после запятой, запись с **экспонентой** (`1e3`) и **слишком большая** сумма (от 10 млрд ₽) — ошибка формата **422**.
- В текстовых полях **пробелы по краям обрезаются**. Пустое значение или одни пробелы — ошибка **«Обязательное поле»**. Исключение — **пароль**: он не обрезается, пробел в нём — ошибка.
- В интерфейсе поля **пустые по умолчанию**; кнопка отправки **неактивна**, пока ввод неверный, и под ней написано **почему** (если причина уже показана красным у поля — «Исправьте ошибку в поле выше»). Пока запрос выполняется, кнопка тоже **неактивна**: двойной клик отправляет **один** запрос.
- Если ошибок несколько, приходит **первая** по порядку: формат поля → счёт → получатель → сумма по тарифу → хватает ли денег → лимиты.
- Ошибки API приходят в **одном формате** (см. [Ошибки API](../03-errors.html)): текст из `message` показывается **у поля** из `field` или **над кнопкой**.
- **Повторный или одновременный** запрос не задваивает результат: операция проводится и деньги списываются **один раз** (повторное подтверждение — **409** «Операция уже завершена»), больше **3 счетов** не открыть, попытки ввода кода не перебрать.
- Время в API — **UTC** (`...Z`), в базе — тоже UTC (колонки без часового пояса), в интерфейсе — **местное**. Сутки и месяц для лимитов и фильтров истории — по **московскому времени**.
