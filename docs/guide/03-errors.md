# Ошибки API

Любая ошибка приходит в одном формате:

```json
{"error": {"code": "own_bank_card", "message": "Пополнить можно только с карты другого банка", "field": "card_number"}}
```

| Поле | Что это |
| --- | --- |
| `code` | постоянный код ошибки — по нему удобно проверять в автотестах |
| `message` | текст, который видит пользователь в интернет-банке |
| `field` | поле запроса, к которому относится ошибка (у поля в форме появится этот текст); `null`, если ошибка общая |

У некоторых ошибок есть дополнительные поля: `attempts_left` (сколько попыток ввода кода осталось), `resend_available_at` (когда можно запросить новый код), `amount_min` и `amount_max` (допустимая сумма).

## HTTP-статусы

| Статус | Когда |
| --- | --- |
| 400 | бизнес-правило: не хватает денег, превышен лимит, получатель заблокирован и т. п. |
| 401 | нет токена или он недействителен — нужно войти заново |
| 403 | пользователь заблокирован |
| 404 | не найден получатель, счёт, операция и т. п. |
| 409 | конфликт с текущим состоянием: уже 3 счёта, карта уже есть, операция уже завершена |
| 422 | неверный формат поля: пусто, не те символы, не та длина, 3 знака после запятой |
| 429 | слишком часто: новый код ещё нельзя запросить |

## Тексты ошибок формата (422)

Код у всех — `validation_error`, в `field` — имя поля.

| Текст | Когда |
| --- | --- |
| Обязательное поле | поля нет, пусто или одни пробелы |
| Должно быть строкой | число, `true` или `null` там, где ждут строку (телефон, пароль, название) |
| Не больше N символов | строка длиннее допустимого |
| Лишнее поле | в теле есть поле, которого нет в описании запроса |
| Телефон: +7 и 10 цифр, например +79001234567 | телефон не разобрался: не те цифры, буквы, `+` не с `+7` |
| Пароль: 8–30 символов без пробелов, строчная и заглавная латинская буква, цифра и спецсимвол | пароль при регистрации не подходит под правила |
| Только буквы, пробел и дефис | в имени или фамилии цифры или знаки |
| Сумма — число, например 1500 или 1500.50 | сумма не число, `1e3`, `NaN`, `true` |
| Сумма должна быть больше нуля | ноль или отрицательная сумма |
| Не больше двух знаков после запятой | `10.123` |
| Слишком большая сумма | от 10 млрд ₽ |
| Только цифры | в номере карты или лицевом счёте есть буквы и знаки |
| Код — 4 цифры | код из SMS не из 4 цифр |
| Срок действия — ММ/ГГ, например 12/30 | срок карты при пополнении не в формате ММ/ГГ |
| CVC — 3 цифры | CVC не из 3 цифр |
| Должно быть целым числом | `id` счёта или операции не число |
| Должно быть не меньше N / не больше N | `limit`, `offset`, `minutes` вне диапазона |
| Дата в формате ГГГГ-ММ-ДД | `date_from` или `date_to` не дата |
| Дата начала позже даты конца | `date_from` позже `date_to` |
| Допустимые значения: … | неизвестное значение фильтра истории (`type`, `status`, `direction`) |
| Некорректный JSON | тело не разобралось как JSON (`field` = `null`) |
| Тело запроса — JSON-объект | тело — массив, строка или число, а не `{...}` |

Цифры везде — только обычные `0`–`9`: «широкие» `１２３４` и другие юникодные цифры дают ошибку формата.

## Все коды

| Код | Статус | Текст | Когда |
| --- | --- | --- | --- |
| `validation_error` | 422 | зависит от поля, например «Обязательное поле», «Телефон: +7 и 10 цифр, например +79001234567», «Некорректный JSON» | неверный формат поля; битый JSON или тело не JSON-объект (`field` = `null`) |
| `client_not_found` | 404 | Клиент с таким телефоном не найден | вспомогательные действия: блокировка несуществующего клиента |
| `invalid_token` | 401 | Нужно войти заново | нет токена или он испорчен |
| `token_expired` | 401 | Сессия истекла, войдите снова | прошло 60 минут с входа (ровно на 60-й минуте токен уже не действует) |
| `invalid_body` | 400 | Некорректное тело запроса: нужен JSON в кодировке UTF-8 | тело не в кодировке UTF-8 |
| `phone_taken` | 409 | Этот номер уже зарегистрирован | регистрация на занятый телефон, в том числе на номер клиента другого банка из справочника |
| `invalid_credentials` | 400 | Неверный телефон или пароль | вход с неверным паролем или неизвестным телефоном |
| `user_blocked` | 403 | Пользователь заблокирован | вход или запрос заблокированного клиента |
| `challenge_not_found` | 404 | Запрос на вход не найден, начните заново | неизвестный `challenge_id`, код уже использован или после него был новый вход |
| `invalid_code` | 400 | Неверный код. Осталось попыток: N | неверный код из SMS |
| `code_expired` | 400 | Срок действия кода истёк, запросите новый | прошло больше 5 минут |
| `code_attempts_exceeded` | 400 | Превышено число попыток ввода кода | третий неверный код; для операции в ответе ещё `operation_status: "DECLINED"` — операция отклонена |
| `resend_too_early` | 429 | Новый код можно запросить чуть позже | не прошло 60 секунд с прошлого кода |
| `account_not_found` | 404 | Счёт не найден | чужой, закрытый или несуществующий счёт (в фильтре истории — чужой или несуществующий) |
| `accounts_limit` | 409 | Можно открыть не больше 3 счетов | открытие четвёртого счёта |
| `account_name_taken` | 409 | Счёт с таким названием уже есть | одинаковые названия (без учёта регистра) |
| `account_not_empty` | 409 | Закрыть можно только счёт с нулевым балансом | закрытие счёта с деньгами |
| `account_has_card` | 409 | К счёту привязана карта — сначала привяжите её к другому счёту | закрытие счёта карты |
| `last_account` | 409 | Нельзя закрыть единственный счёт | закрытие последнего счёта |
| `card_not_found` | 404 | Карта не найдена | у клиента нет карты; номер карты нигде не найден |
| `card_already_exists` | 409 | Виртуальная карта уже выпущена | повторный выпуск карты |
| `recipient_not_found` | 404 | Получатель с таким номером не найден | телефон нигде не найден |
| `recipient_blocked` | 400 | Получатель не может принимать переводы | получатель заблокирован |
| `recipient_no_account` | 400 | У получателя нет открытого счёта | у клиента ShlapaBank все счета закрыты |
| `self_transfer` | 400 | Для перевода себе используйте «Между своими» | перевод на свой телефон или свою карту |
| `invalid_card_number` | 422 | Неверный номер карты | не 16 цифр или не сходится контрольная цифра |
| `card_blocked` | 400 | Карта заблокирована | перевод на заблокированную карту; пополнение с неё — отказ |
| `card_expired` | 400 / 422 | Срок действия карты истёк | перевод на карту с истёкшим сроком (400); срок в прошлом при пополнении (422, поле `expiry`) |
| `own_bank_card` | 400 | Пополнить можно только с карты другого банка | пополнение с карты ShlapaBank |
| `card_no_funds` | — | Банк отправителя отклонил операцию: недостаточно средств на карте | причина отказа пополнения (статус `DECLINED`) |
| `insufficient_funds` | 400 | Недостаточно средств | денег на счёте меньше, чем сумма с комиссией |
| `amount_out_of_range` | 400 | Сумма должна быть от X до Y | сумма вне тарифа операции |
| `limit_per_operation` | 400 | Превышен лимит на одну операцию | сумма с комиссией больше 100 000 ₽ |
| `limit_daily` | 400 | Превышен дневной лимит | за сегодня больше 300 000 ₽ |
| `limit_monthly` | 400 | Превышен месячный лимит | за месяц больше 1 000 000 ₽ |
| `same_account` | 400 | Счета списания и зачисления совпадают | перевод между своими на тот же счёт |
| `operator_not_found` | 404 | Оператор для этого номера не найден | мобильная связь на номер с неизвестным началом |
| `provider_not_found` | 404 | Поставщик не найден | неизвестный код поставщика ЖКХ |
| `invalid_payer_account` | 422 | Лицевой счёт — N цифр | лицевой счёт не той длины |
| `operation_not_found` | 404 | Операция не найдена | чужая или несуществующая операция |
| `internal_error` | 500 | Внутренняя ошибка сервера | непредвиденная ошибка — это баг стенда, сообщите о нём |
| `operation_not_waiting` | 409 | Операция уже завершена | код или отмена для уже проведённой, отклонённой или отменённой операции |
