# SMS

На стенде SMS на телефон не приходят — они видны здесь. Новые сверху, страница обновляется сама. Стенд общий, поэтому сверху могут быть чужие SMS: введите свой телефон в поле — останутся только ваши.

<div id="sms-viewer"></div>

Те же SMS через API (подробнее — [Вспомогательные действия](03-test-api.html)):

| Что | Запрос |
| --- | --- |
| Последние SMS всех клиентов | `GET http://localhost:8080/api/v1/test/sms` |
| Последние SMS на номер | `GET http://localhost:8080/api/v1/test/sms?phone=9991234567` |

Телефон можно писать в любом виде: `9991234567`, `79991234567`, `89991234567`, `%2B79991234567`. Сколько SMS вернуть — `limit` (от 1 до 50, по умолчанию 5), сколько пропустить — `offset`.
