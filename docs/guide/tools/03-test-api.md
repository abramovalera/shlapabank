# Вспомогательные действия (API)

Почти всё на стенде проверяется обычными запросами к банку — так же, как это делал бы клиент. Но несколько вещей так не сделать: SMS никуда не приходят, ждать час до истечения входа или полночь до новых суток — долго, а заблокировать клиента в банке нечем.

Для этого — несколько отдельных запросов. Входить для них не нужно, адреса — от `http://localhost:8080/api/v1`.

!!! warning "Стенд общий"
    Время банка и блокировки меняются **для всех**, кто сейчас работает со стендом. После проверки верните время (`POST /test/time/reset`) и разблокируйте своих клиентов. Сброс — только если со стендом больше никто не работает.

## Какие действия есть

| Зачем | Запрос |
| --- | --- |
| Получить код из SMS | `GET /test/sms?phone=9991234567` — код в поле `code` |
| Перейти на следующие сутки | `POST /test/time/next-day` |
| Прибавить минуты | `POST /test/time/add-minutes` с телом `{"minutes": 6}` |
| Вернуть настоящее время | `POST /test/time/reset` |
| Узнать время банка | `GET /test/time` |
| Заблокировать / разблокировать клиента | `POST /test/users/{телефон}/block` / `unblock` |
| Заблокировать / разблокировать карту ShlapaBank | `POST /test/cards/{номер карты}/block` / `unblock` |
| Вернуть стенд к исходным данным | `POST /test/reset` |

Деньги на счёт кладутся обычным пополнением с карты другого банка — до 50 000 ₽ за раз, [тестовые карты](../02-test-data.html#пополнение-с-карты-другого-банка).

## Как проверить

### Дневной лимит обнуляется в полночь

| Шаг | Что сделать |
| --- | --- |
| 1 | Потратить дневной лимит (300 000 ₽) переводами — следующий перевод даёт «Превышен дневной лимит» |
| 2 | `POST /test/time/next-day` — у банка наступили следующие сутки, 00:00:01 по Москве |
| 3 | Войти заново и сделать перевод — проходит |
| 4 | `POST /test/time/reset` |

### Месячный лимит

| Шаг | Что сделать |
| --- | --- |
| 1 | Тратить по 300 000 ₽ в день, переходя на следующие сутки (`POST /test/time/next-day`), пока за месяц не наберётся 1 000 000 ₽ |
| 2 | Следующий перевод — «Превышен месячный лимит» |
| 3 | Вызывать `next-day`, пока не наступит 1-е число, — месячный лимит снова полный |
| 4 | `POST /test/time/reset` |

### Код из SMS истёк

| Шаг | Что сделать |
| --- | --- |
| 1 | Начать вход или перевод, получить SMS |
| 2 | `POST /test/time/add-minutes` с телом `{"minutes": 6}` — код живёт 5 минут |
| 3 | Ввести код — «Срок действия кода истёк» |
| 4 | `POST /test/time/reset` |

### Вход истёк

| Шаг | Что сделать |
| --- | --- |
| 1 | Войти, получить токен |
| 2 | `POST /test/time/add-minutes` с телом `{"minutes": 61}` — вход действует 60 минут |
| 3 | Любой запрос с токеном — «Сессия истекла, войдите снова» |
| 4 | `POST /test/time/reset` |

### Получателя или его карту заблокировали посреди перевода

| Шаг | Что сделать |
| --- | --- |
| 1 | Зарегистрировать своего клиента-получателя |
| 2 | Начать перевод ему и дойти до ввода кода |
| 3 | `POST /test/users/{его телефон}/block` (или `POST /test/cards/{номер его карты}/block`) |
| 4 | Ввести код — перевод **«Отклонён»**: «Получатель не может принимать переводы» (или «Карта заблокирована») |
| 5 | Разблокировать: `.../unblock` |
